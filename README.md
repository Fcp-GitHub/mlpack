`mlpack` is a Python project suited for machine learning students.
It features a variety of models, each with different levels of verbosity and visualization options, in order to make every algorithm as clear as possible.
Furthermore, it contains notes on Machine Learning concepts.

The project is organized into different sections:
- mlpack: the actual Python package.
- tests:  some examples on how to use the package.
- docs:   notes on different Machine Learning techniques.
